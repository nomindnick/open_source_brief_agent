# Interests

What I want the agent to surface in the morning brief. Edit freely between runs — the agent reads this file at the start of every run.

## High interest

- Local inference: llama.cpp, MLX, vLLM, quantization tricks, KV cache management, long-context techniques
- Small language models (≤30B): pretraining recipes, distillation, training data curation
- Reinforcement learning for LLMs: RLHF alternatives, RLAIF, RL from execution feedback, reward modeling
- Agent architectures: tool use, multi-step reasoning, memory patterns, self-improvement loops
- Retrieval & context: RAG variants, late-interaction retrieval, in-context retrieval, attention over external memory

## Low / no interest

- Pure computer vision (no LLM component)
- Pure robotics / embodied agents
- Cloud-only inference benchmarks with no open-weights component
